# Mod Battle Brother Developer Test
This mod is used to help me to test my mods faster during in game giving me the items that I need and some xp.

# Python script
## deploy_owned_mods
 - requried to install [mod_bb_template](https://github.com/Gujarats/mod_bb_template)
 - run `python deploy_owned_mods.py` to deploy all of my mods if mod_config.json is exist on each mod it will deploy based on that config
 - mod_config.json is a must now because each mod required different directory some are the same but some are not.

## deploy_mods_collections
 - this script used to deploy the mod collections such as vanilla, reforged, legends
 - all those 3 collections mods are not compatible with each other, thus this script helps me to deploy all of them at once
